# 🚀 Malani E-Seva Hub

Malani E-Seva Hub is a modern web application designed to provide a one-stop solution for government digital services, mobile & electronics, and professional photography in Barmer, Rajasthan.

---

## 🏢 Project Overview
This platform streamlines access to essential services for the local community:
- 📝 **E-Mitra government services**
- 📱 **Latest mobile/electronics products**
- 📸 **Mataji Studio's photography offerings**

Optimized for mobile and desktop devices, ensuring a seamless user experience.

---

## 🛠️ Tech Stack
- ⚛️ **React** (TypeScript)
- ⚡ **Vite** (fast development/build)
- 🎨 **Tailwind CSS** (utility-first styling)
- 🏃‍♂️ **Framer Motion** (animations)
- 🧾 **React Hook Form** (form management)
- 🔔 **React Toastify** (notifications)
- ✉️ **EmailJS** (email integration)

---

## ✨ Features

### 📝 E-Mitra Services
- Government forms & certificate applications
- Bill payments & digital services

### 📱 Mobile & Electronics
- Latest smartphones, gadgets, and accessories
- Warranty & after-sales support

### 📸 Mataji Studio
- Professional photography for weddings, events, portraits
- Online booking & digital album delivery

### 💡 Interactive UI
- Responsive design for all devices
- Animated transitions & modern layouts

### 📍 Contact & Location
- Integrated Google Maps for shop location
- Direct contact options

### ♿ Accessibility
- Optimized for mobile & desktop
- Smooth navigation & user-friendly forms

## 🚦 Getting Started
1. 🛒 Clone the repository
2. 📦 Install dependencies: `npm install`
3. 🏃‍♂️ Start the development server: `npm run dev`
