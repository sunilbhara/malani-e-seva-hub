# 🚀 Malani E-Seva Hub

A modern full-stack digital platform built for the Barmer community, providing government services, local business solutions, job updates, and community-driven information in one place.

> Designed with scalability, performance, accessibility, and modern UI/UX principles using React, TypeScript, Supabase, and Tailwind CSS.

# 🚦 Getting Started

## 1️⃣ Clone Repository

```bash
git clone <your-repository-url>
```

## 2️⃣ Install Dependencies

```bash
npm install
```

## 3️⃣ Setup Environment Variables

Create `.env` file:

```env
VITE_SUPABASE_URL=your_supabase_url
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
VITE_EMAILJS_PUBLIC_KEY=your_emailjs_key
```

## 4️⃣ Run Development Server

```bash
npm run dev
```
